# esiesley

Prototipo de la web de la campaña «Que la ESI no quede en blanco» (Brother × Amnistía Internacional Argentina, 2026).

No es un sitio oficial: el formulario de firma no envía nada y los centros de testeo son de ejemplo.

Sitio estático: `index.html` con estilos y scripts adentro, sin build. Cada push a `main` se publica en Vercel.
